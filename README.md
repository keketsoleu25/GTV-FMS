# Tech Alchemy Facilities & Cleaning Template

Reusable mobile-first starter for facilities-management, cleaning and property-support businesses.

## Recycled asset
Recovered from an older client build and generalised for the **Tech Alchemy Template Library**. The historical implementation remains preserved on `main`.

## Includes
Facilities and cleaning service presentation, mobile navigation, quote/enquiry conversion flow, responsive layouts, SEO-ready structure, and static deployment.
